# 3 Good Things

A small installable web app at https://garritymade.com/good-things/. Separate from "the rock is...": own manifest, scope, service worker and icon.

- **Good things tab:** "Write today's three" opens the log page on claude.ai, where the entries, streak and form live. Claude's nightly check-in (a scheduled task) writes to the same log, so both routes count toward one streak.
- **Spiralling? tab:** four short reminders, cached by `sw.js` so they open offline and without signing in. `index.html#spiralling` opens it directly; it's also the home-screen long-press shortcut.

The app itself stores nothing. All entries live in the claude.ai log page's database.

## Files

| File | What |
|---|---|
| `index.html` | The whole app: markup, styles, tabs, install button |
| `manifest.webmanifest` | Name, colors, icons, Spiralling? shortcut |
| `sw.js` | Offline cache for the app shell. Bump `CACHE_VERSION` when a precached file changes |
| `icons/` | Generated by `tools/make_icons.py` (three amber pixel lamps, 16x16 art, nearest-neighbor upscale) |

## Install

Open the page in Chrome and tap **Install** in the header. If that button doesn't show, use the Chrome menu: Add to Home screen or Install app.
